![image](https://github.com/user-attachments/assets/a58d7740-d2a1-45e0-9fc9-e3bec9ba8292)

## Description

This project implements a 3-tier architecture for Roboshop using shell scripts. It sets up the necessary infrastructure and deploys the application components.

## Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/shell-roboshop.git
   cd shell-roboshop
   ```
2. **Run the setup script:**
   ```bash
   bash setup.sh
   ```

## Usage

After successful installation, the Roboshop application will be accessible via your browser. The setup script will provide the necessary URLs and credentials.
